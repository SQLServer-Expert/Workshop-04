# Comece por Aqui

## Workshop SQL Server Expert - 4ª Edição

### Construa Soluções com IA Dentro do SQL Server 2025

Bem-vindo ao Workshop SQL Server Expert 4ª Edição.

Neste workshop você aprenderá na prática como utilizar os novos recursos de Inteligência Artificial do SQL Server 2025 para construir aplicações inteligentes utilizando Embeddings, Busca Vetorial e Retrieval-Augmented Generation (RAG).

```sql
CREATE TABLE dbo.Produto
(
    ProdutoID int IDENTITY(1,1) PRIMARY KEY,
    Nome varchar(100) NOT NULL,
    Preco decimal(10,2) NOT NULL
);
```
---

## Objetivo do Workshop

Ao final do workshop você será capaz de:

* Entender os conceitos fundamentais de IA Generativa
* Criar e utilizar Embeddings dentro do SQL Server
* Implementar Busca Vetorial
* Construir soluções de Hybrid Search
* Desenvolver um RAG completo utilizando SQL Server 2025 e Ollama
* Integrar modelos de linguagem locais utilizando T-SQL
