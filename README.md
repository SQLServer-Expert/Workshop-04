# Workshop SQL Server Expert – 4ª Edição

**Construa Soluções com IA Dentro do SQL Server 2025**

Bem-vindo ao repositório oficial do **Workshop SQL Server Expert – 4ª Edição**.

Neste workshop você aprenderá, na prática, como utilizar os novos recursos de Inteligência Artificial do **SQL Server 2025** para construir aplicações inteligentes utilizando **Embeddings**, **Busca Vetorial**, **Hybrid Search** e **Retrieval-Augmented Generation (RAG)** com modelos locais.

Aqui você encontrará todos os scripts, laboratórios e materiais utilizados durante os dois dias do workshop.

---

# 📂 Organização do Repositório

O conteúdo está organizado na mesma sequência utilizada durante o workshop.

## 📁 01-Preparacao

Materiais para preparação do ambiente antes do início do workshop.

Conteúdo:

- Instalação do SQL Server 2025
- Instalação do SQL Server Management Studio (SSMS)
- Instalação do Ollama
- Configuração do Caddy
- Validação do ambiente
- Scripts iniciais

---

## 📁 02-Dia01-Sab

Conteúdo desenvolvido durante o primeiro dia.

Principais assuntos:

- Fundamentos de IA Generativa
- Large Language Models (LLMs)
- Engenharia de Prompt
- Modelos Externos
- Embeddings
- Tipo de dado VECTOR
- AI_GENERATE_CHUNKS
- AI_GENERATE_EMBEDDINGS

---

## 📁 03-Dia02-Dom

Conteúdo desenvolvido durante o segundo dia.

Principais assuntos:

- Busca Vetorial
- Vector Search
- Hybrid Search
- Full-Text Search
- Vector Index
- DiskANN
- RAG (Retrieval-Augmented Generation)
- Projeto completo utilizando SQL Server 2025 e Ollama

---

# ✅ Pré-requisitos

Para executar os laboratórios é recomendado possuir:

- SQL Server 2025
- SQL Server Management Studio (SSMS)
- Ollama
- Caddy
- Git (opcional)

As instruções de instalação encontram-se na pasta **01-Preparacao**.

# 📖 Sobre o Workshop

O Workshop SQL Server Expert é um treinamento intensivo e totalmente prático, criado para profissionais que desejam aprender a utilizar os recursos mais modernos do SQL Server em cenários reais.

Durante o evento todos os exemplos são executados ao vivo e cada laboratório pode ser reproduzido utilizando os materiais disponíveis neste repositório.
